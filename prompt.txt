Vamos a trabajar en este proyecto me vas a ayudar paso a paso. Crearemos la constitucion luego la especificacion, plan y tareas por cada caracteristica. Deben haber 5 requerimientos funcionales y no funcionales y 5 de riesgo. Deben ser 3 caracteristicas, API, persistencia y Frontend. Para la API se debe usar python con fastapi y el CLI de uv, los documentos al ser pequeños no hay necesidad de dividirlos en chunks solamente se le pasa el documento correspondiente al LLM para que responda basandose en el. Se debe usar openrouter y un modelo gratuito como deepseek o el que consideres mejor, en el .env ya se encuentra la key. Para la persistencia se debe usar sqlite. El front debe funcionar con react y hacer uso de npm. La interfaz debe ser parecida a la de chatgpt con un panel al lado izquiero con las preguntas realizadas previamente. Antes de seguir con un nuevo paso (por ejemplo agregar una caracteristica o el frontend)  debes consultarme para continuar. Las sugerencias son bienvenidas con el fin de completar este proyecto de la mejor manera.
